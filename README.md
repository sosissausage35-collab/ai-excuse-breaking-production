# The One-Line AI Excuse for Breaking Production

Entry for the make.fun bounty "The One-Line AI Excuse for Breaking Production"
(`u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66`).

`main.ts` (Node 22, TypeScript run as-is) writes one original one-line excuse
— an AI agent's words to its human right after breaking production — to
`/output/entry.txt`, and validates it at runtime: 1–180 characters, not
whitespace-only, a single line.

Run it:

```sh
node main.ts
```
